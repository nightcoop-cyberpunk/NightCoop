# NightCoop

**NightCoop** is the fan night coop build for cyberpunk 2077 coop, aka nightcoop mod and nightcoop cyberpunk. It maps how hosts fit eight players over red4ext, with guests joining a session through an invite link.

## Host a run
1. Extract the archive into the game folder you already own.
2. Start the game; coop sits in the menu.
3. Host, or join through an invite link.
4. Notes in `files/notes/`.
